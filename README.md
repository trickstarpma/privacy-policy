# プライバシーポリシー

本アプリケーション「無劣化トリマー - 爆速動画カット」（以下、「本アプリ」）における利用者情報の取り扱いについて、以下のとおり定めます。

### 1. 収集する情報とその利用目的
本アプリは、お客様の個人情報（氏名、メールアドレス、電話番号、位置情報等）を取得・収集・利用することは一切ありません。

### 2. 動画データおよびファイルアクセスについて
本アプリは、動画のトリミング処理を行うためにのみ端末内のメディアファイルへのアクセスを使用します。
すべての動画編集および処理はユーザーの端末内（ローカル）でのみ行われ、外部のサーバーや第三者へ動画データが送信されることは一切ありません。

### 3. 広告について
本アプリには広告は含まれておらず、広告配信に伴う追跡・データ収集も行っておりません。

### 4. お問い合わせ
本ポリシーに関するお問い合わせは、デベロッパーの連絡先までお願いいたします。
